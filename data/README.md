# Benchmark and data provenance

The primary project does not require a downloaded or restricted dataset. It generates deterministic four-neighbor obstacle grids inside the executed notebook.

## Dataset identity and access

- Dataset name: **Synthetic deterministic obstacle-grid benchmark**.
- Origin: generated by the benchmark code in `src/Graph_Search_Evolutionary_Optimization.ipynb`; no external dataset or hosted data source is used.
- Source URL/citation: not applicable because the benchmark is generated locally. The algorithm references are listed in the root README and report.
- Local filename/path used: no external input file. The generator is in the notebook, and the generated scenario metadata is saved to `results/experiment_manifest.json`.
- Schema: `experiment_manifest.json` records scenario size, density, seed, reachability retry, start/goal, obstacle count, terrain mode, and terrain-cost values. The result schemas are the column headers in `results/algorithm_comparison.csv`, `results/stochastic_trials.csv`, and `results/convergence.csv`.
- Access instructions: install the requirements and execute the notebook from the repository root; it regenerates the benchmark and all result files without a download or credential.

## Generation procedure

- Grid sizes: 15x15, 25x25, and 35x35.
- Obstacle densities: 0.15 and 0.25.
- Modes: unit-cost and weighted terrain.
- Weighted terrain costs: {1, 3, 7} for traversable cells.
- Scenario seeds: 7000 through 7011.
- GA seeds: 11, 22, 33, 44, and 55.
- The generator reserves the start and goal cells and retries with a deterministic seed offset until a route exists.

The exact generated scenario metadata is stored in results/experiment_manifest.json. The notebook regenerates the same benchmark and writes the machine-readable result files.

Raw grids, generated caches, and temporary notebook outputs are excluded from version control because they are reproducible from the committed generator and manifest. The committed CSVs, manifest, figures, and executed notebook are the reviewable project artifacts.
