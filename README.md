# Graph Search and Evolutionary Optimization

**Timeline:** October 2024  
**Category:** Main project

This project studies uninformed and informed graph search together with evolutionary optimization. It implements BFS, DFS, IDS, best-first search, priority-queue expansion, heuristic path reconstruction, and genetic-algorithm operators for selection, crossover, mutation, fitness, and convergence analysis.

## Stack

Python, graph traversal, BFS, DFS, IDS, best-first search, priority queues, heuristics, path reconstruction, genetic algorithms, selection, crossover, mutation, fitness, and convergence analysis.

## Repository contents

- `src/` — search and optimization implementations.
- `reports/` — project documentation.
- `data/README.md` — graph/task-input provenance and excluded-data instructions.
